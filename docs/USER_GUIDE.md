## Что такое mxEditorJs

mxEditorJs заменяет TinyMCE/CKEditor в менеджере MODX. Контент состоит из **блоков**: параграф, заголовок, картинка, галерея, таблица, видео. Каждый блок редактируете, перетаскиваете и удаляете отдельно.

---

## Начало работы

1. **Система → Системные настройки**
2. `which_editor` = **mxEditorJs**
3. `mxeditorjs.enabled` = **Да**
4. Откройте ресурс — в поле контента появится редактор

Редактор не появился? См. [Частые вопросы](#редактор-не-появляется).

## Работа с редактором

### Добавить блок

- **Enter** в конце блока — новый параграф
- **«+»** слева от блока — меню типов блоков

### Переместить блок

Наведите на блок → иконка ⋮⋮ слева → перетащите.

### Удалить блок

⋮⋮ → **Delete**.

### Форматирование текста

Выделите текст — появится панель: **B**, **I**, **Link**, **Code**, **Marker**, **U**.

## Типы блоков

| Блок | Назначение |
|------|------------|
| **Paragraph** | Основной текст, inline-форматирование, выравнивание |
| **Header** | Заголовки H2–H5 (уровень меняется в тулбаре блока) |
| **List** | Маркированный или нумерованный список |
| **Checklist** | Список с чекбоксами |
| **Quote** | Цитата с необязательной подписью |
| **Table** | Таблица, первая строка может быть заголовком |
| **Code** | Блок кода без форматирования |
| **Raw HTML** | Произвольный HTML без фильтрации |
| **Delimiter** | Горизонтальная линия |
| **Warning** | Заголовок и текст предупреждения |
| **Attaches** | Файл для скачивания (PDF, DOC, ZIP и др.) |
| **Image** | Одно изображение с подписью и настройками |
| **Gallery** | Несколько изображений, сортировка, fit или slider |
| **Embed** | Видео и встраиваемый контент (см. ниже) |

Набор блоков зависит от профиля. Администратор настраивает его через `mxeditorjs.profile` или `mxeditorjs.enabled_tools`.

---

## Изображения

1. **«+»** → **Image**
2. **Загрузить** — drag-and-drop или выбор файла
3. **Обзор** — браузер Media Source с навигацией по папкам

После вставки доступны: подпись, рамка, растягивание, фон, CSS-пресет (если настроен администратором).

**Форматы:** JPG, JPEG, PNG, GIF, WebP, SVG.  
**Размер по умолчанию:** до 5 МБ (`mxeditorjs.max_upload_size`).

---

## Галерея

Блок **Gallery** объединяет несколько изображений в одном месте.

1. **«+»** → **Gallery**
2. Добавьте картинки через **Загрузить** или **Обзор** (тот же Media Source, что у Image)
3. Перетащите миниатюры для смены порядка
4. В настройках блока выберите режим:
   - **fit** — сетка
   - **slider** — горизонтальная прокрутка
5. При необходимости добавьте общую подпись

Администратор может ограничить число картинок через `mxeditorjs.gallery_max_count`. Значение `0` снимает лимит.

---

## Ссылки

1. Выделите текст → **Link**
2. Введите URL или начните набирать название ресурса MODX — сработает автодополнение по pagetitle, longtitle и ID
3. Настройте target, rel и CSS-класс (если настроены пресеты)

## Видео и встраиваемый контент

Кнопки **Embed** в меню нет. Вставьте URL в пустой блок (Ctrl+V / Cmd+V) — редактор создаст embed-блок сам.

**Поддерживаемые сервисы:** YouTube, Vimeo, RuTube, Twitter/X, Instagram, CodePen и другие из `@editorjs/embed`.

RuTube распознаётся по ссылке вида `https://rutube.ru/video/...`.

После сохранения на сайте отображается iframe-плеер.

## Дополнительные поля (TV)

Редактор работает в TV типа **Textarea** с опцией **Rich Text** = **Да**.

1. Создайте TV (Textarea, Rich Text = Да)
2. Назначьте шаблону
3. Откройте ресурс → вкладка **Дополнительные поля**

Каждое TV получает свой экземпляр редактора и отдельное хранилище JSON. Автомиграция HTML для TV **не выполняется** — только для основного контента ресурса.

---

## Полноэкранный режим и просмотр HTML

Над редактором две кнопки:

| Кнопка | Действие |
|--------|----------|
| **Fullscreen** | Редактор на весь экран (F11, выход — Escape) |
| **Source** | HTML-предпросмотр текущего контента (Ctrl+U / Cmd+U), только чтение |

---

## Миграция из HTML

Если у ресурса есть HTML от старого редактора, но нет JSON в sidecar, при первом открытии появится окно миграции:

1. Превью: число блоков и размер HTML
2. **Мигрировать** — конвертация в блоки Editor.js
3. **Отмена** — пустой редактор

Мигратор распознаёт: заголовки, параграфы, списки, цитаты, картинки, таблицы, код, разделители. Embed, галерею, вложения и чеклисты из HTML **не восстанавливает** — добавьте их вручную после миграции.

Миграция затрагивает только основной контент ресурса, не TV.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Enter` | Новый блок |
| `Backspace` в пустом блоке | Удалить блок |
| `Tab` / `Shift+Tab` | Вложенность в списке |
| `Ctrl+B` / `Cmd+B` | Жирный |
| `Ctrl+I` / `Cmd+I` | Курсив |
| `Ctrl+K` / `Cmd+K` | Ссылка |
| `Ctrl+Z` / `Cmd+Z` | Отменить |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Повторить |
| `Ctrl+U` / `Cmd+U` | Source Preview |
| `F11` | Полноэкранный режим |
| `Escape` | Выйти из полноэкранного режима |

## Частые вопросы

### Редактор не появляется

1. `which_editor` = **mxEditorJs**
2. `mxeditorjs.enabled` = **Да**
3. `use_editor` = **Да**
4. **Система → Очистить кэш**

### Редактор не появляется в TV

1. TV: **Textarea**, **Rich Text** = **Да**
2. Откройте вкладку **Дополнительные поля**
3. Редактор инициализируется при появлении поля на странице

### Не добавляется видео

Вставьте ссылку (YouTube, RuTube и т.д.) в пустой блок через Ctrl+V. Отдельной кнопки Embed нет.

### Картинка не загружается

Проверьте у администратора: Media Source, права на папку, размер (до 5 МБ по умолчанию), формат (JPG, PNG, GIF, WebP, SVG).

Подробнее: [OPERATIONS.md](OPERATIONS.md), [CONFIGURATION.md](CONFIGURATION.md).
